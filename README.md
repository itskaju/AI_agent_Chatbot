# AI Agent Chatbot with FastAPI

An AI-powered chatbot application built using **FastAPI** and **Python** that provides intelligent, context-aware conversations through a simple web interface.

## 🚀 Features

- AI-powered chatbot
- FastAPI backend
- Interactive frontend
- REST API integration
- Modular and scalable project structure
- Easy to deploy

## 📦 Installation

### Clone the repository

```bash
git clone https://github.com/itskaju/AI_agent_Chatbot.git
cd AI_agent_Chatbot
```

### Install dependencies

Using pip:

```bash
pip install -r requirements.txt
```

Or using Pipenv:

```bash
pipenv install
```

## ▶️ Run the Application

```bash
uvicorn backend:app --reload
```

Open your browser and visit:

```
http://127.0.0.1:8000
```

## 📸 Output

The application provides an interactive chatbot interface where users can ask questions and receive AI-generated responses.
